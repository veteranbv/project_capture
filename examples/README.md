# Project Capture Examples

## Quick Start

Basic usage example showing different capture scenarios:

```bash
python quick_start.py
```

This demonstrates:
- Basic capture with default settings
- Custom ignore patterns
- AI-ready format with prompt wrapper
- Performance tuning options

## Progress Tracking

Example showing real-time progress tracking with Rich:

```bash
python progress_demo.py
```

This demonstrates:
- Integration with Rich progress bars
- Progress callback usage
- File type statistics
- Performance metrics

## Running Examples

Make sure you're in the project root with the virtual environment activated:

```bash
source venv/bin/activate
cd examples
python quick_start.py
```

All examples write their output to the `output/` directory.

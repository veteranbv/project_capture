Project Capture is an AI-ready project snapshot tool that captures your codebase
in formats optimized for Large Language Models (LLMs). It provides both CLI and
web interfaces, supports parallel processing, and offers flexible configuration
options.

Key Features
------------

* 🧠 **AI-Ready**: Captures project contents in formats optimized for AI/LLM consumption
* 🎨 **Modern UI**: Intuitive web interface using Streamlit and CLI with Rich
* 📁 **Smart Filtering**: Granular control over gitignore patterns and custom rules
* 🚀 **Performance**: Parallel processing and memory-efficient streaming
* 💾 **Multiple Formats**: Support for Markdown, JSON, and more (coming soon)
* 🔧 **Configurable**: Project-specific configurations with templates

Quick Start
-----------

Install Project Capture::

    pip install project-capture

Run the CLI::

    project-capture

Or launch the web interface::

    project-capture --web
